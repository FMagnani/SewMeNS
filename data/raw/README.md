# Raw Data

This folder contains raw input data used for the analysis of replicated sewage sampling sites.

## Files
- meta_location.csv: metadata describing sample locations and site replication structure  
- genomic_species_abundance.csv: species-level abundance table derived from metagenomic sequencing  

## Source
Data downloaded from Figshare:  
https://figshare.com/articles/dataset/25016147  

## Notes
- Files are stored as originally downloaded (no modifications applied)  
- All preprocessing, normalization, and network inference steps are performed in downstream analysis scripts
